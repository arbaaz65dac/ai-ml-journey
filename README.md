# 🔎 Retrieval-Augmented Generation (RAG)

RAG is an important part of the GenAI learning path in this repository.

The learning process focuses on understanding how external knowledge can be retrieved and provided to an LLM so that responses can be grounded in relevant information.

### RAG Pipeline

```text
Documents
    ↓
Document Loading
    ↓
Text Splitting / Chunking
    ↓
Embeddings
    ↓
Vector Storage
    ↓
Similarity Search
    ↓
Relevant Context
    ↓
LLM
    ↓
Generated Response
```

### Key Concepts

- Document loading
- Document processing
- Text splitting
- Chunking
- Embeddings
- Vector representations
- Similarity search
- Retrieval
- Context injection
- LLM generation
- RAG pipelines

The objective is to understand the complete RAG pipeline rather than treating it as a pre-built abstraction.
